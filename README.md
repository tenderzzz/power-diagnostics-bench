# 电源异常诊断实验台

围绕“输出电压跌落，怎样通过测量区分原因？”制作的本地双语交互实验。

## 打开

双击 **启动实验台.command**。它会启动本机服务并打开浏览器。保留终端窗口；结束使用时按 Ctrl+C。

也可以在项目目录运行：

```sh
npm start
```

浏览器打开终端显示的地址，默认是 `http://127.0.0.1:8771`。端口占用时会选择后续空闲端口。需要 Node.js 20 或更新版本；没有第三方运行依赖，无需执行安装命令。

## 完成一次实验

1. 在“引导实验”中施加测试脉冲，观察 5 V 输出。
2. 选择输入跌落、负载突变或电容退化，改变相应参数。
3. 点击器件、测试点或测量按钮，测量输入电压和负载电流；可继续查看电感电流、开关节点和微秒尺度纹波。
4. 进入“验证修复”，只改变一个条件，对照修复前后波形。
5. 进入诊断挑战，完成三个未知案例。提交判断前需要交叉测量；判断正确后还需要复测确认。

完成复测后，可导出实验 JSON 与当前捕获的全量波形 CSV。JSON 包括修复前后参数、模型版本、指标及原始测量证据；CSV 的列名包含单位。

中英切换保留当前实验、测点、游标与诊断进度。语言偏好保存在浏览器本地；实验数据保留在当前页面内，刷新后重新开始。

## 实现与验证

- 原生 HTML / CSS / JavaScript，SVG 器件、Canvas 示波器、Web Worker 计算。
- 每次计算包含 15 ms 稳态初始化与 12 ms 记录；每条捕获约 63,600 个采样点。
- 图形、数值与诊断依据都来自同一次通用 Buck 开关仿真。
- 本地运行不请求模型、字体、脚本或统计服务。模型说明中的原厂资料链接仅在主动打开时访问。
- 键盘可操作全部主要控件，减少动态效果时跳过回放动画。

```sh
npm run check   # 物理关系、收敛、异常、修复、边界与双语检查
npm run verify  # 保存数值核验记录到 evidence/numerical-checks.json
npm run build   # 生成可由静态服务器托管的 dist/
```
